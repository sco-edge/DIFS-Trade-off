## DIFS
### Overview

This project benchmarks and analyzes the trade-offs between inference 
latency and generation accuracy across different 
versions of Diffusion Models to optimize production serving.

### Models Version & Evaluation Metrics

* **Models(Stable Diffusion)**:
  - SD v1.5
  - SD v2.1
  - SDXL
  - SD v3.5  

* **Evaluation Metrics**:
  - Latency
  - Accuracy: CLIP, FID
